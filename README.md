# 덕영고등학교 DYCN 사이트 소개

덕영고등학교 DYCN 팀이 만든 사이트는  
진학정보, 워게임 추천, 커뮤니티, 그리고 DYCN 팀 소개로 구성되어 있습니다.

---

## 사이트 구성

### 1. 진학정보  
학생들이 학교 진학과 관련된 최신 정보를 쉽게 확인하고, 체계적인 진학 준비를 할 수 있도록 지원합니다.

### 2. 워게임 사이트 추천  
실전 해킹 능력 향상을 위한 다양한 워게임 사이트를 엄선하여 소개함으로써 학생들의 학습 효과를 높입니다.

### 3. 커뮤니티  
학생들 간 자유로운 소통 공간을 제공하여, 지식과 경험을 공유하고 협업할 수 있는 환경을 만듭니다.

### 4. DYCN 팀 소개  
DYCN 팀의 목표와 활동 내용을 소개하며, 팀의 비전과 학생 역량 강화를 위한 노력을 알립니다.

---

덕영고 DYCN 팀의 이 사이트는  
정보 전달과 커뮤니티 활성화를 통해 학생들의 진학과 보안 역량 성장을 동시에 지원하는 플랫폼입니다.
